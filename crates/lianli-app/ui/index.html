Settings

      

        
        
RGBable's logon task is disabled, so it won't start with Windows. Enable "RGBable at logon" in Task Scheduler.

      

      

        
OpenRGB

        
RGBable uses OpenRGB for RAM, GPU, motherboard and other lighting. Let RGBable run it in the background as administrator so it can reach your RAM; you won't need to open OpenRGB yourself.

L-Connect

        
Only one program can talk to the Lian Li devices. Turn off L-Connect's "start with Windows" and exit it; RGBable waits until it has closed.

      

      

        
Device setup

        
Walk through every light again: blink it, name it, put it in a group and choose whether All Devices changes it.

        

      

      

        
Updates

        
RGBable checks GitHub for new versions when it starts and every few hours. Dev builds are untested and come out with every change.

        

          
          
          
          
        

      

      

        
      

      

        
White balance

        
LEDs make pure white look slightly blue. Warm it up until white looks white to you; it applies to every device and effect.

Restart

        
Restarts RGBable, and OpenRGB too when RGBable runs it, so newly plugged-in devices such as a keyboard are found. Lighting comes back on its own.
